= FAQ

== 1. How is this NeoDash different from NeoDash Labs?

It is a fork of NeoDash 2.4, the open source dashboard builder from Neo4j Labs, made to run as a
shared service on Kubernetes:

- A server holds the Neo4j credentials and runs every query. Browsers never connect to Neo4j, and
there is no connection screen.
- Users sign in through your identity provider (for example Keycloak), and have the viewer or
editor role. See link:../publishing[Publishing].
- Dashboards are listed on a start page and have their own addresses, which include the page and
parameter values.
- It works with Neo4j Community Edition, and makes no requests to the internet (this
documentation is part of it).

Dashboards made with NeoDash 2.x open unchanged.

== 2. Is NeoDash free to use?

Yes. NeoDash is available under the
https://www.apache.org/licenses/LICENSE-2.0[Apache 2.0 license].

== 3. Can I publish the dashboard that I built?

Yes: save it, and everyone who can sign in to NeoDash can open it. Viewers can use it but not
change it. See link:../publishing[Publishing].

== 4. Can I use NeoDash with Neo4j Community Edition?

Yes. Community Edition has a single user database and no database roles, so access is controlled
by NeoDash instead: viewers' queries run read-only, and only the queries saved in dashboards run
for them. Neo4j Enterprise Edition works too.

== 5. Why does a report show "No answer from the server"?

The answer to the report's query didn't arrive within the report's time limit plus 30 seconds,
for example because a network connection dropped. Run it again with the report's *Refresh* button
(if the report has one), or reload the page.

== 6. Where do I report a problem or ask for a feature?

Ask the team that runs NeoDash for you. Issues with this version of NeoDash itself can be raised
on its https://github.com/p-kimberley/neodash/issues[GitHub repository].
