
= Graph

The graph report will render all returned nodes, relationships and paths
in a force-directed graph layout. This includes collections (lists) of
these objects.

The library `react-force-graph` is used to create the visualizations.
Depending on your computer, the visualization should be able to handle
drawing 1000-3000 nodes/relationships with custom styling options.

The graph layout contains an extensive set of features, including:

- Drag and drop nodes.
- Custom node/relationship styling.
- Clicking a node or relationship shows its properties in a pop-up next to it. Clicking elsewhere or pressing Escape closes it.
- Right-clicking a node opens a menu to inspect it, expand its neighbours (*Expand...* lists its relationship types with how many there are) and, if editing is enabled, edit it.
- A search box that finds nodes by their labels and properties, with buttons to step through the matches.
- Buttons to fit the graph to the view, lock the layout, and switch between 2D and 3D (see xref:user-guide/reports/graph3d.adoc[3D Graph]). Without WebGL (e.g. on some remote desktops), graphs are always drawn in 2D.

Expanding and editing run queries that aren't saved in the dashboard, so they only work for editors.

== Examples

=== Basic Graph

....
MATCH (p:Person)-[a:ACTED_IN]->(m:Movie)
WHERE m.title = 'The Matrix'
RETURN p, a, m
....

== Virtual Graph

....
MATCH (p:Person)-[:ACTED_IN]->(m:Movie)<-[:ACTED_IN]-(p2:Person)
WHERE m.title = "The Matrix"
RETURN p, p2, apoc.create.vRelationship(p, "KNOWS", {}, p2)

== Advanced Settings

[width="100%",cols="12%,2%,3%,83%",options="header",]
|===
|Name |Type |Default Value |Description
|Node Color Scheme |List |default |The color scheme to use for the node
labels. Colors are assigned automatically (consecutively) to the
different labels returned by the Cypher query. The default scheme has
separate, contrast-checked colors for light and dark mode (reports saved
with the old default, neodash, use it too).

|Node Label Color |Color |black |The color of the node captions, drawn just
below each node with a halo in the background color. Left at black, captions
follow the light or dark appearance.

|Node Label Font Size |Number |3.5 |Size of the labels drawn on the
nodes.

|Node Size |Number |2 |Default size of a node in the graph
visualization. This size is applied if no custom size styling is defined
and no Rule-Based styling is active.

|Node Size Property |Text |size |Optionally, the name of the node
property to map to the node size. This lets you define sizes on a
node-specific level, if you have a property that directly maps to the
numeric size value.

|Node Color Property |Text |color |Optionally, the name of the node
property to map to the node color. This lets you define colors on a
node-specific level, if you have a property that directly maps to the
HTML color value.

|Relationship Color |Text |#a0a0a0 |The color used for drawing the
relationship arrows in the visualization.

|Relationship Width |Number |1 |The (default) width of the relationship
arrows in the visualization.

|Relationship Label Color |Text |#a0a0a0 |The color of the labels
(relationship type) drawn next to the relationship arrows.

|Relationship Label Font Size |Number |2.75 |The font size of the labels
(relationship type) drawn next to the relationship arrows.

|Relationship Color Property |Text |color |Optionally, the name of the
relationship property to map to the arrow color. This lets you define
colors on a relationship-specific level, if you have a property that
directly maps to the HTML color value.

|Relationship Width Property |Text |width |Optionally, the name of the
relationship property to map to the arrow width. This lets you define
widths on a relationship-specific level, if you have a property that
directly maps to the width value.

|Animated particles on Relationships |on/off |off |If enabled, draw
relationships with animated particles on them, moving in the direction
of the relationship.

|Speed of the particle animation |Number |0.005 |How fast the particles move.

|Arrow head size |Number |3 |Use this to set the length of the arrow head, size is adjusted automatically.
If 0, no arrow will be drawn.

|Background Color |Color |#fafafa |The background color of the
visualization.

|Graph Layout (experimental) |List |force-directed |Use this to switch from
the main (force-directed) layout to one of the experimental layouts:
tree-top-down, tree-bottom-up, tree-left-right, tree-right-left or radial. For the experimental layouts, make sure
your graph is a DAG (directed acyclic graph).

|Tree layout level distance |Number |30 |The distance between the levels of a tree layout.

|Enable graph exploration |on/off |on |Lets editors expand nodes: right-click a node and choose *Expand...*, then a relationship type to traverse. Data is retrieved in real time and not cached in the visualization.

|Enable graph editing |on/off |off |Lets editors edit nodes and relationships from the right-click menu, and create new relationships with the relationship types and property keys in the database. Changes are written to the database.

|Show pop-up on Hover |on/off |off |If enabled, shows a pop-up when a
user hovers over one of the nodes/relationships in the visualization.
The pop-up contains the label and properties of the node/relationship.

|Show properties on Click |on/off |on |If enabled, shows the label and properties of a node/relationship in a pop-up when a user clicks it.

|Fix node positions after Drag |on/off |on |If enabled, locks in
(freezes) the node positions after a user drags them.

|Enable locking node positions |on/off |on |Shows a button that locks (freezes) the layout of the whole graph.

|Node Label images |Text |(no value) |Images drawn instead of the nodes of a label, as JSON: `{"Person": "data:image/png;base64,..."}`. Use images the browser can load from your network, or data URIs.

|Drilldown Icon Link |Text (URL) |(no value) |Specifying a URL here will
display a floating button on the top right of the visualization. This
button can be used to drilldown into a different tool so
that the graph can be explored further. Dynamic Dashboard Parameters
(e.g. $neodash_person_name) can be used in these links as well.

|Enable CSV Download |on/off |off |Shows a button that downloads the query results as a CSV file.

|Hide Property Selection |on/off |off |If enabled, hides the property selectors
(below the visualization).

|Override no data message |Text |Query returned no data. |Override the message displayed to the user when their query returns no data.

|Auto-run query |on/off |on |When activated, automatically runs the query
when the report is displayed. When set to off, the query is displayed
and will need to be executed manually.

|Selector Description |Markdown text | |When specified, adds a button to the report header that opens a pop-up with the rendered markdown from this setting.
|===

== Rule-Based Styling

Using the xref:user-guide/extensions/rule-based-styling.adoc[Rule-Based Styling] menu, the
following style rules can be applied to the graph: 

- The background color of a node. 
- The label color of a node.
