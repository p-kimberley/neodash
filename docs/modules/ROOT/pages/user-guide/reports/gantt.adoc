
= Gantt Chart

link:../../extensions/advanced-visualizations[label:Advanced&nbsp;Visualization[]]

A Gantt chart can be used to visualize tasks on a timeline, as well as their dependencies.
The NeoDash Gantt chart views your tasks as nodes in the graph, and your relationships as dependencies between them.

To use the Gantt chart, nodes must have at least three properties on them (their names can be changed in the advanced settings):

- A `startDate`
- An `endDate`
- A `name`

In addition, different types of task dependencies can be visualized. The dependency must be stored as a property on a relationship, and can be one of four values:

- `**SE**`: The dependency is from the **S**tart of the origin task, to the **E**nd of the next task.
- `**SS**`: The dependency is from the **S**tart of the origin task, to the **S**tart of the next task.
- `**ES**`: The dependency is from the **E**nd of the origin task, to the **S**tart of the next task.
- `**EE**`: The dependency is from the **E**nd of the origin task, to the **E**nd of the next task.

== Examples

=== Gantt Chart
Return nodes and relationships to be visualized in the chart.
It is mandatory to specify the three node properties (start date, end date and title) in the report's advanced settings.

[source,cypher]
----
MATCH (a:Activity)-[r:FOLLOWS]->(a2:Activity)
RETURN a, r, a2
----

== Advanced Settings

[width="100%",cols="15%,2%,6%,77%",options="header",]
|===
|Name |Type |Default Value |Description
|Bar Color |Text |#a3a3ff |Default color for the task bars (with no style rules applied).

|Task Label Property |Text |name |Node property to display on the task bar.

|Task Start Date Property |Text |startDate |Node property to use as a start date for the task.

|Task End Date Property |Text |endDate |Node property to use as an end date for the task.

|Task Ordering Property |Text |(auto) |Custom ordering of the tasks. Defaults to use the start date property.

|Dependency Type Property |Text |rel_type |The relationship property that stores the dependency type: SS, SE, ES or EE.

|View mode |List |auto |Zoom level of the chart: auto, Half Day, Day, Week, Month, Quarter or Year.

|Override no data message |Text |Query returned no data. |Override the message displayed to the user when their query returns no data.

|Auto-run query |on/off |on |When activated, automatically runs the query when the report is displayed. When set to off, the query is displayed and will need to be executed manually.

|Selector Description |Markdown text | |When specified, adds a button to the report header that opens a pop-up with the rendered markdown from this setting.
|===
