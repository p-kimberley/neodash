
= Choropleth

link:../../extensions/advanced-visualizations[label:Advanced&nbsp;Visualization[]]

A Choropleth chart will render geographical data in geoJson polygons
layout. It takes two fields: 

- *code*: String. The country code: ISO 3166 Alpha-3 by default; Alpha-2 or numeric codes can be chosen with the *Country code format* setting.
- *value*: Number. The value to color the country by.

The country shapes are bundled with NeoDash, so the chart works without internet access.

== Examples

=== Basic Choropleth




[source,cypher]
----
MATCH p=(n:Wine)-[:IS_FROM|PART_OF*]->(c:Country)
WITH DISTINCT c.iso3 as country, count(DISTINCT n) as wines
RETURN country, wines
----

== Advanced Settings

[width="100%",cols="15%,2%,26%,57%",options="header",]
|===
|Name |Type |Default Value |Description
|Country code format |List |iso_a3 |The ISO standard of the country codes: iso_a3 (three letters), iso_a2 (two letters) or iso_n3 (numeric).

|Background Color |Color |#fafafa |The background color of the visualization.

|Enable Interactivity |on/off |on |If enabled, shows a tooltip and highlights a country when the mouse is over it.

|Show Legend |on/off |on |If enabled, shows a color legend.

|Color Scheme |List |default |The color scheme to use for the choropleth. The default is one hue, light (few) to dark (many), reversed in dark mode. Country colors
vary from the lowest to the highest value.

|Polygon Border Width (px) |Number |0 |The width of the border of each
country.

|Margin Left (px) |Number |24 |The margin in pixels on the left side of
the visualization.

|Margin Right (px) |Number |24 |The margin in pixels on the right side
of the visualization.

|Margin Top (px) |Number |24 |The margin in pixels on the top side of
the visualization.

|Margin Bottom (px) |Number |40 |The margin in pixels on the bottom side
of the visualization.

|Projection Scale |Number |100 |The zoom level of the map.

|Projection X translation |Number |0.5 |Moves the center of the map horizontally (0 to 1).

|Projection Y translation |Number |0.5 |Moves the center of the map vertically (0 to 1).

|Tooltip Property |Text |properties.name |The property of the country shape shown in the tooltip, e.g. `properties.name` for the country's name.

|Override no data message |Text |Query returned no data. |Override the message displayed to the user when their query returns no data.

|Auto-run query |on/off |on |When activated, automatically runs the
query when the report is displayed. When set to off, the query is
displayed and will need to be executed manually.

|Selector Description |Markdown text | |When specified, adds a button to the report header that opens a pop-up with the rendered markdown from this setting.
|===
