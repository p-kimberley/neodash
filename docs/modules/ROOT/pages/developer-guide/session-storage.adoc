= Session Storage

The `sessionStorage` part of the state (`src/sessionStorage/`) holds values that should only last for the current session, such as an extension's temporary data. They are not saved with the dashboard.

To use it, pick a key and use the actions in `src/sessionStorage/SessionStorageActions.ts`:

- `setSessionStorageValue(key, value)` stores a value, and `deleteSessionStorageValue(key)` removes it.
- `deleteAllKeysInSessionStorageWithPrefix(prefix)` removes every key starting with a prefix, e.g. to clear all of one extension's data.
- `getSessionStorageValue(state, key)` and `getSessionStorageValuesWithPrefix(state, prefix)` in `SessionStorageSelectors.ts` read them back.

For example, Build with AI keeps each report's earlier descriptions under a per-report key with a common prefix (`getSessionStorageHistoryKey` in `src/text2cypher/state/QueryTranslatorSelector.ts`) (`deleteAllKeysInSessionStorageWithPrefix` clears keys by such a prefix).
