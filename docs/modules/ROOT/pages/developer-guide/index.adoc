== How it fits together

NeoDash is one container: a Node.js backend that serves the web app, signs users in and runs every Neo4j query.

- *Browser*: the React app. It never connects to Neo4j and never sees its credentials; it calls the backend's `/api` (`src/api/client.ts`). Reports still receive Neo4j driver values, decoded from the backend's typed JSON (`src/api/ApiDriver.ts`, `src/api/neo4jValues.ts`).
- *Backend* (`server/`): signs users in with OpenID Connect (e.g. Keycloak), takes their role (viewer or editor) from the identity token, stores dashboards in Neo4j as `_Neodash_Dashboard` nodes (the same format as NeoDash 2.4), runs queries (read-only, saved queries only, for viewers), writes JSON audit lines, and asks a language model to build reports (Build with AI) if one is configured.
- *Neo4j*: Community or Enterprise 5. It holds the dashboards and the data.
- *Documentation*: these pages are built into the app by `scripts/build-docs.mjs` and served at `/docs`, so they can be read without internet access.

== What it's built with

The web app is written in TypeScript:

- https://react.dev/[React] 19 with https://redux.js.org/[Redux] 5 and https://redux.js.org/usage/writing-logic-thunks[thunks]
- The https://neo4j.design/[Neo4j design system] (NDL 4, `@neo4j-ndl/react`) for buttons, menus, dialogs, form fields and the table (its data grid, on https://tanstack.com/table[TanStack Table])
- https://webpack.js.org/[Webpack] and Tailwind (with NDL's `n-` prefixed classes)

The visualizations use:

- https://echarts.apache.org/[Apache ECharts]: bar, line, pie, radar, sankey, sunburst, treemap, circle packing, choropleth and gauge charts
- https://github.com/vasturiano/react-force-graph[react-force-graph]: 2D and 3D graphs
- https://maplibre.org/[MapLibre GL JS]: map and area map
- Frappe Gantt (a copy in `src/extensions/advancedcharts/chart/gantt/frappe`): the Gantt chart
- https://github.com/remarkjs/react-markdown[react-markdown]: markdown
- CodeMirror (`@neo4j-cypher/react-codemirror`): the Cypher editor

The backend uses https://fastify.dev/[Fastify], the official Neo4j JavaScript driver, `openid-client` and `zod`, on Node.js 22.
Tests use https://playwright.dev/[Playwright] (browser) and https://vitest.dev/[Vitest] (backend).
