= Quickstart

== Using NeoDash

Open the NeoDash address your administrator gave you and sign in. You start on the list of
dashboards: search it by name or author, sort it by name or by when dashboards were last updated,
and click one to open it.

Editors also see *New dashboard*, to start building one. See link:user-guide/dashboards[Dashboards]
to get going, and link:user-guide/reports[Reports] for the types of report you can add.

If you are signed in but can't open NeoDash, your account doesn't have the viewer or editor role
yet: ask your administrator.

== Running NeoDash

NeoDash runs on Kubernetes, installed with its Helm chart, next to a Neo4j 5 server (Community or
Enterprise) and an OpenID Connect identity provider such as Keycloak. See
link:developer-guide/deploy-a-build[Deploy a Build].

To try it on your own machine, the repository's `dev/` folder starts everything with Docker:
Neo4j Community with example data and dashboards, Keycloak with test users (`viewer` and
`editor`, password `password`), and NeoDash on http://localhost:3000.

....
docker compose -f dev/compose.yaml up -d --build
....

To work on NeoDash itself, see link:developer-guide/build-and-run[Build & Run].
